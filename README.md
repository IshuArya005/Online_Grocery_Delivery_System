# 🛒 Online Grocery Shop

📌 Project Overview

The **Online Grocery Shop** is a full-stack web application that allows users to browse grocery products, add items to their cart, and place orders through a secure and user-friendly interface. The platform also provides an **Admin Dashboard** to manage products and monitor orders.

This project was developed using **HTML, CSS, JavaScript, React.js, Node.js, Express.js, and MongoDB**.

# ⚙️ Installation

## Clone the Repository

```bash
git clone https://github.com/your-username/Online-Grocery-Shop.git
```

---

## Install Dependencies

### Frontend

```bash
cd client
npm install
```

### Backend

```bash
cd server
npm install
```

---

## Start the Project

### Backend

```bash
npm start
```

### Frontend

```bash
npm start
```

The application will run on:

```text
http://localhost:3000
```

# 🔄 Workflow

1. User opens the website.
2. User signs up or logs in.
3. Browse grocery products.
4. Select products.
5. Add products to the cart.
6. Cart updates automatically.
7. Proceed to checkout.
8. Choose a payment method.
9. Confirm the payment.
10. Order is placed successfully.
11. Admin can manage products and orders from the dashboard.
